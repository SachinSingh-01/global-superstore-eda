# Global Superstore EDA

## Project Overview
This project analyzes the Global Superstore dataset to identify key business insights related to sales performance, profitability, customer behavior, product performance, and regional trends.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Business Questions
- Which products generate the highest sales and profit?
- Which regions perform best?
- How do discounts affect profitability?
- Who are the most valuable customers?
- Which products generate losses?

## Key Findings
- Technology is one of the most profitable categories.
- High discounts negatively impact profit.
- Certain customers contribute a large share of revenue.
- Some products generate significant losses despite strong sales.
- Regional performance varies considerably.

## Project Structure
- Data Cleaning
- KPI Dashboard
- Time Series Analysis
- Product Analysis
- Regional Analysis
- Customer Analysis
- Shipping Analysis
- Correlation Analysis
- Business Recommendations
